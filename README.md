Bohrium Playground Period 4 submission — challenge `benchmark-a1d81ca4` (track: `literature-reading`).

This repository holds the complete skill package for the challenge: the skill
definition, its executable entry point and all supporting scripts. No precomputed
answers, private data or credentials are included.

## Skill

- Name: `literature-benchmark-runner`
- Summary: Use when a literature-reading evaluation workorder must be scored item by item with deterministic rules and failure analysis.

## How to run

```bash
python scripts/run_skill.py --case /input/case.json --output /app/output/result.json
```

The entry point is `SKILL.md`; input/output contracts, error handling and a minimal
usage example are documented there.

## Notes

- Pure Python standard library; no network access required.
- The result JSON keeps the input case id, the main results, per-item evidence,
  a run status and an uncertainty section.
